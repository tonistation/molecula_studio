Molecula Studio / Plan UX / Baja fidelidad

Un borrador que se puede retomar.

Seis pantallas propuestas para un estudio local. M1: guardar/abrir JSON. M2: prueba audiovisual de 10–15 s con fixture, sin editor completo. M3: editor básico y proveedores opcionales con aprobación explícita. M4: pulido y validación final.

Solo diseño. No es un producto funcional. Todos los campos, botones, revisiones, tiempos y estados son representaciones estáticas. No guardan archivos, no generan contenido, no reproducen ni exportan. Solo funcionan los enlaces de navegación de este documento.
